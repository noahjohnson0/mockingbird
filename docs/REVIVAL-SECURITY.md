# Security work before reviving mockingbird

Mockingbird was packed away on 2026-10-25. These gaps came out of a security review that day. Fix them before putting the nodes back on a network.

1. **OTA has no password.** `startOTA()` in `firmware/esp32-wroom-mockingbird/src/main.cpp` never calls `ArduinoOTA.setPassword()`/`setPasswordHash()`, so anyone on the Mockingbird SSID can flash any leaf over UDP 3232. Add a password hash in `secrets.h` (generated by `scripts/gen-esp32-secrets.sh`) and pass `--auth` via `upload_flags` in the `ota` env of `platformio.ini`.
2. **The leaf HTTP API is unauthenticated.** `:80` serves `/`, `/version` and `/restart`; any client can reboot a node. Put `/restart` behind a token or drop it.
3. **The collector accepts any stream.** `services/mockingbird-collector.py` on `pi:9001` takes NDJSON from any host. Restrict it to `10.0.8.0/24` with nftables on the Pi, or add a shared token to the uplink.
4. **The subnet route exposes the whole mesh to the tailnet.** The Pi advertises `10.0.8.0/24`, so every tailnet device reaches the leaves' OTA and HTTP ports. Add a Tailscale ACL that limits the route to the operator's Mac, or stop advertising it when it isn't needed.
5. **Plaintext credentials.** The Pi sudo password and the Opal admin password live in plaintext files under `~/repos/.secrets/`. Move them to the macOS keychain and have `bootstrap-pi-subnet-router.sh` read them with `security find-generic-password`.
6. **Patch on revival.** Update Raspberry Pi OS, Tailscale and the Opal's GL.iNet firmware. Re-check that stock Dropbear on Opal port 22 is disabled now that OpenSSH runs on 2222.
7. **Re-register with `/surface`.** Rows H11–H14 in `~/.claude/skills/surface/surfaces.md` were marked dormant; set them back to active once the fixes above are in.
